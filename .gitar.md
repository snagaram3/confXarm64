# Gitar

Review instructions live in [`.gitar/review/`](.gitar/review/). Auto-apply criteria: [`.gitar/config/apply.md`](.gitar/config/apply.md).

GitHub Actions CI is `.github/workflows/ci.yml` (`npm test` and `npm run build`). Gitar diagnoses failing CI. Do not add SonarQube or SonarCloud jobs.

Connect Gitar while signed in via Settings → Configuration (not the Marketplace app while signed out): https://docs.gitar.ai/connecting-code/github
Grant the app access to `snagaram3/confXarm64`. Enable auto-apply on a PR with `gitar auto-apply:on` or the `gitar-managed` label.
