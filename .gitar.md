# Gitar (Sonar) review brief — Floorwise

Use this file as the PR review prompt for Gitar / Sonar on the Never Merge Broken track. The app must stay demoable without Gitar.

## What this repo is

Floorwise is a conference companion for Salt Palace. Ranking of sessions and booths MUST go through Elasticsearch (`POST /api/rank`, `POST /api/sponsor/:id/visitors`). Do not accept PRs that move Must/Maybe/Meh scoring back to in-memory JavaScript.

## Checks for every PR

1. `npm run build` succeeds.
2. Demo script still works: late-for-255 wayfinding, map recolor on profile change, crowd take on a Must pin, Elastic sponsor mirror.
3. `/api/rank` remains the source of rank colors. `src/lib/ranking.ts` may hold labels/defaults only — not catalog scoring.
4. OpenTelemetry stays optional: unset `OTEL_EXPORTER_OTLP_ENDPOINT` must not crash the API.
5. Seeded catalog still has 8–12 sessions and 4–6 booths across floors 1–3, including room 255.
6. No ARKit/ARCore, beacons, heatmaps, or auth.

## Out of scope

Live Dash0 credentials, a real cluster for Radar, and Gitar itself are optional for local `npm run dev`.
